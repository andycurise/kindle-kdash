# kdash v0.4.0

首个按多平台开源发布流程整理的版本。主机负责天气、农历和灰度图渲染，Kindle PW2 只通过局域网拉图显示。

## 支持平台

- Windows 11 x86-64：当前用户登录计划任务。
- Linux x86-64 / ARM64：systemd 系统服务。
- macOS Apple Silicon：当前用户 LaunchAgent。
- Kindle Paperwhite 2：Shell 客户端与 KUAL 扩展，不包含 Go ARM 程序。

Windows 登录任务和 macOS LaunchAgent 都不会在用户未登录时运行。

## 快速安装

以下命令使用官方仓库 `andycurise/kindle-kdash`，并固定到 `v0.4.0`。

### Windows 11

```powershell
& ([scriptblock]::Create((irm -Uri 'https://github.com/andycurise/kindle-kdash/releases/download/v0.4.0/install.ps1'))) -Repo 'andycurise/kindle-kdash' -Version 'v0.4.0' -NonInteractive
```

### Linux

```sh
curl -fsSL https://github.com/andycurise/kindle-kdash/releases/download/v0.4.0/install.sh | sudo bash -s -- --repo andycurise/kindle-kdash --version v0.4.0 --non-interactive
```

### macOS Apple Silicon

```sh
curl -fsSL https://github.com/andycurise/kindle-kdash/releases/download/v0.4.0/install.sh | bash -s -- --repo andycurise/kindle-kdash --version v0.4.0 --non-interactive
```

安装器会校验 `SHA256SUMS`、生成随机管理令牌、保留已有配置并请求 `/api/status`。普通 Windows 安装不需要最高权限；Linux 系统服务需要 sudo。

Kindle 用户下载 `kdash-kindle-pw2.zip`，按包内 `README.md` 配置 `SERVER_URL`。使用远程前光切换时，再配置与服务端一致的 `SETTINGS_TOKEN`。

## 本版本重要变化

- 新增四平台构建、五类归档、两个安装器和 SHA-256 清单。
- 新增安装、升级、回滚、卸载和 Release 校验文档。
- Windows 启动脚本不再强制覆盖配置文件端口。
- 管理修改接口统一 POST/PUT 与鉴权；空令牌只允许带防 CSRF 请求头的本机回环首次设置。
- 环境变量令牌不再落盘，Unix 私密配置权限为 `0600`。
- 前光保存失败不再返回成功；并发配置保存保持磁盘和内存一致。
- Kindle `REFRESH_SECONDS` 实际生效，SSH 部署默认严格校验主机密钥。
- 默认不再优先使用明文 HTTP 空气质量镜像。
- 补齐 MIT、全部字体 OFL 和 Go 依赖 NOTICE。

## 升级注意

- `/api/set-frontlight` 不再接受 GET；请同步更新 Kindle KUAL 脚本。
- 配置文件现在拒绝未知字段，升级前删除旧架构的 `output_png`、`stay_awake_cmds` 等字段。
- 局域网管理写操作需要 `settings_token`。安装器首次安装会自动生成；手动升级需要自行设置。
- 升级保留活动配置，但仍建议先备份服务端 `kdash.json` 和 Kindle `client.conf`。

## 校验与发布状态

`SHA256SUMS` 覆盖五个 ZIP/tar 归档。安装器会自动校验；手动下载命令见 `RELEASES.md` 或仓库 `docs/releases.md`。

本版本不承诺 Authenticode、macOS 公证、Sigstore、SBOM 或 provenance。SHA-256 不能独立证明发布者身份。

本地已执行 Go 全量测试、race detector、四平台构建、归档检查、macOS 模拟安装和离线 HTTP/浏览器验收。GitHub 三系统 CI、真实 Win11/Linux 服务生命周期及 Kindle 真机结果需要在对应环境单独确认，不能由本机结果替代。
